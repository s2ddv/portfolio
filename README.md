# Samuel Barbosa — Portfólio

Portfólio em React e Vite com estudos de caso do [Astra Wealth](https://github.com/s2ddv/astra-wealth) e do [Monte Carlo GBM](https://github.com/s2ddv/monte-carlo-gbm).

## Desenvolvimento

```bash
npm ci
npm run dev
npm run build
```

## Design

A interface usa uma paleta de azul profundo e verde água. As cores são tokens em `src/index.css`:

| Papel | Cor |
| --- | --- |
| Fundo | `#0b1120` |
| Superfície elevada | `#111b2e` |
| Texto principal | `#f3f6fa` |
| Texto secundário | `#aab8cb` |
| Acento | `#82d7c6` |
| Divisórias | `#304055` |
| Gráfico quant | `#a9b8ed` |

O projeto inclui navegação por teclado, link para pular ao conteúdo, foco visível, alvos de ação confortáveis, layout responsivo e respeito à preferência por movimento reduzido.

## Conteúdo

As descrições distinguem funcionalidades documentadas de pesquisa e trabalho em desenvolvimento. Atualize os estudos de caso em `src/App.jsx` quando os projetos mudarem.
